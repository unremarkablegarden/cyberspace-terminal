# Stockfish.js 19.0.1

The lite, single-threaded Stockfish 19 WebAssembly engine is bundled here and
runs locally in a web worker. It makes no chess API or AI service requests.

Stockfish.js and the Stockfish engine are licensed under GPL-3.0; the full
license is in `Copying.txt`. The exact browser build and build scripts are
available at [nmrugg/stockfish.js v19.0.1](https://github.com/nmrugg/stockfish.js/tree/v19.0.1).
The [Stockfish 19 release notes](https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.0)
identify its upstream engine revision as
[official-stockfish/Stockfish edb0d9d](https://github.com/official-stockfish/Stockfish/tree/edb0d9d)
and the lite engine revision as
[f5e5c633](https://github.com/official-stockfish/Stockfish/commit/f5e5c633dd0c9c0efd1d1266f441ea5929b043c1).
The [Stockfish networks repository](https://github.com/official-stockfish/networks)
states that its network files are released under CC0.
