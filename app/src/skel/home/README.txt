Home directory. Persists in this browser.

Examples:
  echo hello > hi.txt
  cat hi.txt
  ls -l
  history

~/bin        your programs. Manual in ~/bin/docs.
~/public_html
             your site, at pages.cyberspace.online/<user>/ — supporters
             only. Logged in, the directory syncs: edit, cp, rm and
             upload write straight to it. Start with index.html.

Sync         supporters only. Logged in, the home follows you between
             devices: after login, every minute while the tab is
             visible, before logout and shutdown, or by name: sync.
             End to end encrypted. Files and names are sealed on this
             device under a key wrapped by your login password; the
             server holds ciphertext, sizes and a revision. Lose every
             logged-in device and the password and the copy on the
             server is unreadable. A file edited on two devices is kept
             as both, the other's beside it as <name>.1. Skipped:
             public_html, bin/docs, bin/examples, .sh_history, *.tmp.
             5 MiB, 256 files, 1 MiB per file. sync reset starts over
             from this device; it asks.
