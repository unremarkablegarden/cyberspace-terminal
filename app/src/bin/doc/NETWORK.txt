WHAT IT IS

One REST API at https://api.cyberspace.online. login, circ, cmail,
feed, browse and publish are clients of it. A program can be another.

login(1) is POST /v1/auth/login. It holds the session and renews the
token; nothing on this machine asks for it again.


FROM A PROGRAM

  const me = await ctx.api.get('/v1/users/me')
  await ctx.api.post('/v1/posts', { body: 'hello' })

Paths must start with /v1/. The request carries the identity of the
member running the program, and the server enforces their permissions
and their rate limits. No token is handled by the program. A failed
connection throws NO CARRIER.

Web programs only. A program for this machine has fetch and no
credential; its API calls are unauthenticated.


WHAT IS THERE

  /v1/auth            log in, refresh, verify
  /v1/users           members, profiles, the caller's own account
  /v1/posts           the feed
  /v1/replies         threads
  /v1/follows         who follows whom
  /v1/bookmarks       saved posts
  /v1/notifications   notifications
  /v1/circ            rooms, messages, presence
  /v1/cmail           conversations
  /v1/guilds          groups
  /v1/topics          tags
  /v1/search          members and posts
  /v1/programs        the gallery browse and publish use
  /v1/pages           ~/public_html
  /v1/settings        the caller's own preferences
  /v1/notes           private notes
  /v1/watches         subscriptions

Every route, field and error code is in the spec, which is the
reference; this list is a summary.


ENVELOPES

A route answers { data }. A list adds { cursor }; a null cursor is
the last page. A failure answers { error: { code, message } }.

ctx.api hands back the data alone, so a cursor is not reachable through
it. A filtered page can come back short, or empty, with more behind it.


THE TERMS

An account with a verified email address. Unverified, an authenticated
request is refused with 403 EMAIL_NOT_VERIFIED. Accounts are created on
the website; there is no signup endpoint.

No scraping: no bulk collection of posts, replies or profiles for
redistribution, archival or analysis outside a personal client.

No bots: no automated account that posts, replies, follows or reacts
without a human driving each action.

No AI systems: no training, fine-tuning, embedding or evaluation on
Cyberspace content, and no agent reading or writing through the API on
a member's behalf.

The API is for personal clients driven by a person.
