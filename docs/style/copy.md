# Machine copy

Everything the terminal prints: motd, prompts, errors, program output, hints.

## Register

Old Unix. Ultra curt, fewest words possible, for a proficient operator.

- Impersonal and specific. No pronouns addressed to the operator, no chat register, no whimsy.
- Silent on success.
- Prompts end in a colon: `Login:`, `Password:`.
- Errors name the thing and the failure: `Login incorrect`, `ls: No such file or directory`.
- Period strings where they exist: `NO CARRIER`, `The system is going down for reboot NOW.`
- Strings from the original /terminal are reused verbatim: `F1 Config`, `Type help for commands`.
- Key hints are the key and one word: `F1 Config`, never `F1 opens terminal configuration`.
- The terminal fonts have no em dash. Write shorter sentences or use commas.

## Examples

| Not | But |
| --- | --- |
| `F1 opens terminal configuration` | `F1 Config` |
| `Oops, that password didn't work` | `Login incorrect` |
| `Your home is now synced!` | (nothing) |
